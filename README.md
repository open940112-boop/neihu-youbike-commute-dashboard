# 內湖科技園區通勤看板

即時查看台北市內湖區 YouBike 2.0 站點車況，協助科技園區通勤者掌握可借車與可還空位。

## 功能

- 瀏覽器直接讀取臺北市 YouBike 2.0 即時 JSON，每 60 秒更新，也可手動更新。
- 只顯示 `sarea` 為「內湖區」且營運中的站點。
- 顯示可借車總數、可還空位總數、營運站點數，以及各站可借車低於容量 20% 的提醒。
- 以折線圖記錄本次開啟期間的可借車總量變化；每次成功更新記錄一個點。
- 可搜尋站名或地址、排序站點，或只看低車量站點。
- 適用手機與桌面；抓取失敗時保留上次成功資料並自動重試。

## 使用方式

直接以瀏覽器開啟 `index.html` 即可。也可用任何靜態網站代管服務部署本資料夾；例如 GitHub Pages 可將來源設為 `main` 分支的根目錄。資料 API 由使用者瀏覽器直接請求，無需 API 金鑰或自建後端。

## 資料來源與欄位

- 提供機關：臺北市政府交通局
- 資料集： [臺北市 YouBike2.0 即時資訊](https://data.gov.tw/dataset/137993)
- API：[`youbike_immediate.json`](https://tcgbusfs.blob.core.windows.net/dotapp/youbike/v2/youbike_immediate.json)
- 欄位用途：`sarea` 區域、`act` 營運狀態、`Quantity` 站點總容量、`available_rent_bikes` 可借車數、`available_return_bikes` 可還空位、`mday`/`srcUpdateTime` 資料更新時間。
- 資料集標示依「政府資料開放授權條款－第 1 版」利用，頁面提供來源與授權連結。

## 規格對照

本專案依參考需求實作：直連開放資料、每分鐘自動更新、顯示資料時間與抓取時間、三項統計數字、車量折線趨勢、站點搜尋與低車量提醒、手機版版面、錯誤提示與上次成功資料保留，以及資料來源與授權標示。

## 檔案

- `index.html`：看板結構與內容
- `styles.css`：桌面與手機版樣式
- `app.js`：資料更新、篩選、統計、提醒與圖表
